# TaskFlow-To-Do App

TaskFlow is a simple task management application developed using **Flutter and Dart** as part of Phase 4 of my Flutter Development Internship at **GeniuSoft**.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks with an Undo option
- Mark tasks as completed or pending
- View completed and pending task counts
- Search tasks
- Save tasks locally using SharedPreferences

## Technologies Used

- Flutter
- Dart
- SharedPreferences
- flutter_launcher_icons

## Topics Covered

- Lists in Dart
- CRUD Operations
- Local Storage
- Flutter State Management

## Design

The application features a clean interface with a dark navy, soft blue, and white color theme.
